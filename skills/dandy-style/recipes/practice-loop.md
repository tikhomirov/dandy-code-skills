# Recipe: Practice Loop

## Source

Based on `content/099-after.md`: understandable and predictable code wins in real projects. Style develops by noticing names, method size, and everyday clarity.

## Problem

The user wants improvement but the agent turns it into a one-time grand refactor.

## Good behavior

- Improve code every day in small passes.
- Prefer predictable over clever.
- Make one visible improvement per review when scope is small.
- Build taste by comparing before/after examples.

## Bad signs

- The agent proposes a giant rewrite.
- The agent optimizes for clever architecture instead of clarity.
- The plan has no small first step.

## How to apply

1. Pick one concrete code area.
2. Apply one or two recipes.
3. Verify behavior.
4. Note what became easier to read.
5. Repeat later.
